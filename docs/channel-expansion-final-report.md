## 未接入渠道

Bing 本轮未接入。官方 Bing Search API 已退役，普通网页搜索或新闻搜索结果不具备明确的热榜语义，也未发现同时满足稳定、可验证、非 RSS 条件的第三方 Bing 热榜源。强行接入会把普通搜索结果伪装为趋势榜单，因此保持不注册、不生成空卡片。

## 稳定性措施

- 数据源遵循“官方非 RSS -> 稳定第三方 -> RSS”顺序；使用 RSS 时只进入统一 RSS 卡片。
- TodayHot 默认最小请求间隔 3 秒，DailyHot 默认最小请求间隔 5 秒；两者均有进程缓存和 403/429 冷却。
- DailyHot 仅作为快手的第三级备用源，不是默认来源。
- Hacker News 最多读取 25 个详情并输出 20 条，单条失败不会拖垮整个渠道。
- 东方财富使用一次批量请求补充股票名称和行情；行情增强失败时保留代码榜单。
- 无有效榜单的失败快照会在下一轮立即重试，不再被旧 `fetchedAt` 阻塞；单渠道失败仍保留最近成功快照。

## 残余风险

Google Trends、快手和百度依赖页面内结构化数据，新浪、网易、澎湃和东方财富依赖公开但无 SLA 的接口；页面或接口结构变化仍可能导致采集失败。现有结构校验、失败隔离、旧快照保留和 Actions 网络探测可暴露这类变化，但不能替代上游稳定性保证。
