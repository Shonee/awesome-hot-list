# 实施计划

1. 先以测试固定 `Ranking.surface`、快讯窗口、报告过滤、部分榜单合并和 RSS 退役契约。
2. 优化日报标题聚类候选集，并消除日终渲染对相邻日期的重复读取和构建。
3. 实现必应国内热点、新浪/财联社/华尔街见闻 7x24，以及 Readhub、央视新闻、外交部适配器。
4. 调整注册表、采集 CLI 和 GitHub Actions：新增 15 分钟 live 任务，移除 RSS 环境变量与默认调度。
5. 移除页面 RSS 功能，增加快讯时间样式与榜单类型处理，保持现有顶层导航。
6. 更新仓库说明，运行全量单元测试、Node UI 测试、编译、YAML/差异检查和本地浏览器验收。

## 性能与目录补齐

1. 以测试固定内容面文件分流、老 `latest.json` 迁移和采集不再同步构建报告的契约。
2. 将注册表扩展为显式声明每个渠道支持的 `surface`，并按内容面分别落盘。
3. 前端实现热榜优先加载、其他内容面空闲补载，以及基于 DOM 预算的卡片渐进挂载。
4. 改造 Actions：采集只更新快照，渲染任务每小时统一更新报告，Pages 接受 live 任务触发。
5. 新增渠道目录生成器、基线/当前全量快照、增量变更格式和 CI 一致性校验。
6. 执行全量测试、报告耗时、gzip 体积、首屏 DOM 数量、桌面/移动端滚动加载与降级路径验收。
