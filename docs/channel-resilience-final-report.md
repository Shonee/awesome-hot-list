# 渠道韧性与页面优化完成报告

## 完成内容

- 首页顺序固定为“最新热榜、今日报告、历史报告”；移动端每榜展示前 10 条并取消卡片内部纵向滚动，桌面端保持原有条数和滚动方式。
- 渠道配置拆分为默认采集、默认展示和报告参与三个维度。福利吧每小时采集、默认隐藏且不进入报告；脉脉三项默认关闭，仍可配置 Cookie 后手动采集和展示。
- Linux.do 和 IT之家使用官方 RSS 并归入统一 RSS 卡片，不再生成独立卡片。RSS 部分源失败会提示具体来源。
- 腾讯新闻使用官方 JSON，雪球使用官方接口；失败时分别降级到 TodayHot。共享 Provider 实施进程级缓存、最小请求间隔以及 403/429 批次冷却。
- 今日与最近 7 日历史报告支持跨日新增、持续、升温、降温和掉榜分析；综合评分加入榜单百分位、渠道覆盖、持续度和新鲜度，并新增按调度频率计算的采样完成度。
