现实中，一些企业所谓“电池自研”，主要集中在电池包设计、系统集成、BMS管理甚至产品定义层面，与真正完成电芯研发并实现大规模稳定制造，并不是同一个概念。目前不少车企的相关布局尚未深入到电芯制造核心环节。

动力电池本身就是资本、技术、人才和制造高度密集的产业。规模化制造尤其需要长期的工艺积累和质量控制，绝不是建起厂房、买来设备，就自然形成产业竞争力。如果每一家整车企业都追求“大而全”，每一个环节都重复投资，每一种能力都要求内部解决，看似增加了自主性，实际上可能带来新的低水平重复建设和资源错配。

现代工业的真正竞争力，恰恰建立在专业化分工之上。我们当然需要更多动力电池企业成长，需要更多技术路线竞争，也需要整车企业增强自身技术能力。但“多元化”与“去龙头化”不是一回事，“自主创新”与“什么都自己做”也不是一回事。

产业竞争可以激烈，技术路线可以不同，供应链也可以多元。但有一条底线不能模糊：不能让低质量内卷损害中国新能源产业来之不易的竞争优势，不能让营销概念替代真正的技术创新，更不能把产业链协同人为变成产业链对立。](https://finance.sina.cn/7x24/2026-09-22/detail-inisspzi5661930.d.html)
